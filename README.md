# TAKA 888 — Sports Betting UI Demo

A responsive, front-end-only sports interface inspired by common sports odds dashboards.

## Included
- Responsive mobile/desktop layout
- Sample football, cricket, and tennis fixtures
- Illustrative sample odds
- Virtual balance and demo bet slip
- No real-money deposits, withdrawals, account system, or live odds

## Run locally
Open `index.html` in a browser.

## Publish with GitHub Pages
1. Sign in to GitHub and create a new repository, e.g. `taka888-demo`.
2. Choose Public (or another option supported by your GitHub Pages plan), then create the repository.
3. Select **Add file → Upload files**.
4. Upload `index.html` and `README.md` from this folder, then commit the changes.
5. In the repository, open **Settings → Pages**.
6. Under Build and deployment, select **Deploy from a branch**.
7. Select branch `main` and folder `/ (root)`, then click **Save**.
8. Wait for deployment. GitHub Pages will show the published URL in Settings → Pages.
